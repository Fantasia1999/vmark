Markdown 工作台

像 VS Code 一样打开整个文件夹作为工作区，浏览并预览其中的 Markdown；也可以只打开单个文件。

本地工作区使用 File System Access API。SSH/WSL 需本机桥接 npm run ssh-bridge（WSL 仅 Windows + wsl.exe）。也可直接打开 file://wsl.localhost/… 路径。

最近工作区

    最近文件

      打开 WSL 工作区

      通过本机 Bridge 读取发行版内的 Markdown（需 Windows + 已启动 bridge）

      填写发行版内部路径，例如 /home/you/repo，不是 Windows 盘符。

      支持 \\wsl$\…、\\wsl.localhost\…、 wsl://Distro/…、file://wsl.localhost/…

      打开 SSH 工作区

      经本机 Bridge 连接远程目录。凭证仅发送到 127.0.0.1。
