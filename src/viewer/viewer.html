Markdown 工作台

像 VS Code 一样打开整个文件夹作为工作区，浏览并预览其中的 Markdown；也可以只打开单个文件。

本地工作区使用 File System Access API。SSH/WSL 需本机桥接 npm run ssh-bridge（WSL 仅 Windows + wsl.exe）。也可直接打开 file://wsl.localhost/… 路径。

打开 WSL 工作区

通过本机 Bridge 调用 wsl.exe 读取发行版内文件。也可粘贴 \\wsl$\Ubuntu\home\…、wsl://Ubuntu/home/… 或 file://wsl.localhost/…。

打开 SSH 工作区

通过本机 SSH Bridge 连接远程目录并预览 Markdown。密码/私钥仅发送到本机 127.0.0.1 桥接进程。
